# 📊 AI Stock Market Data Analyzer

An AI-powered Stock Market Analysis Platform built using Python, Streamlit, and Yahoo Finance API.  
It provides real-time stock analytics, AI-based trading signals, portfolio comparison, and risk analysis in a clean interactive dashboard.

---

## 🚀 Live Demo
👉 https://stock-market-data-analyzer-hlghpyjustmhfhae62ruzd.streamlit.app/

---

## 🧠 Project Overview

The AI Stock Market Data Analyzer helps users:
- Analyze stock price movements
- Visualize historical trends
- Generate AI-based Buy / Sell / Hold signals
- Evaluate financial risk
- Compare multiple stocks in a portfolio

It simulates a real-world FinTech analytics system used in trading and investment decision-making.

---

## 📌 Features

### 📊 Stock Analytics
- Candlestick charts
- Moving Averages (MA20, MA50)
- Historical price visualization
- Interactive Plotly graphs

### 🤖 AI Trading Signals
- Buy / Sell / Hold recommendations
- Trend detection using moving averages
- Rule-based AI logic for decision support

### 📈 Portfolio Analysis
- Compare multiple stocks side-by-side
- Correlation visualization
- Performance tracking over time

### ⚠ Risk Analysis
- Volatility calculation
- Sharpe ratio estimation
- Maximum drawdown analysis

### 📄 Report Generator
- Download stock data as CSV
- Dataset preview
- Basic financial summary stats
